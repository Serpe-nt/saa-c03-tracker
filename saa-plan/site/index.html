🗺 Where things happen: 4 separate places

AWS splits learning, the actual cloud, and exam booking into different sites with different logins. Every step says which one it uses.

① Skill Builder

skillbuilder.aws
  • The learning site you already use (login: AWS Builder ID).
  • Essentials videos, Cloud Quest, Exam Prep Plan.
  • Free. One month of subscription in week 2.
  • It is not an AWS account — you can't build anything here.

② Cloud Quest lab sandbox

opened from inside Cloud Quest
  • Each assignment's lab opens a temporary AWS account that AWS gives you.
  • Real AWS console, wiped after the lab.
  • Free. No card, no setup.

③ Your own AWS account

console.aws.amazon.com
  • A real, permanent cloud account you create on Day 1.
  • Needs a card. Free plan gives credits, so labs should cost $0.
  • Used for every Build step.

④ Certification account

aws.training → Certification
  • Only for booking and managing the exam.
  • Booking hands you over to Pearson VUE (the exam provider).
  • Online from home or at a test centre.

Rules: watch Essentials at 1.5–2×, then play the matching Cloud Quest assignments. Do each DIY challenge without opening the solution. Labs beat videos — if short on time, cut video, never labs. In ③ your own account, delete what you built every day. For every wrong practice answer, write why each wrong option is wrong. Dotted-underlined terms on a step show a definition on hover.

Each day ends with a 30-question quiz you pass at 90%. Around it: reviews of what you missed, a quick service drill, your wrong-answer notebook, a weak-spot map, and a full mock exam once Days 1–13 are done.

Resource names follow the published outlines of AWS Cloud Practitioner Essentials (13-module version), AWS Cloud Quest: Cloud Practitioner and the Exam Prep Enhanced Course (SAA-C03); a few Essentials module titles may be worded slightly differently in your view. Cloud Quest unlocks assignments in its own order — if one is locked, skip it with Next, play the following one and come back. Quiz and mock questions are original practice questions written in the exam's style, not official AWS questions. Progress is saved on the server when it runs from Docker, and in this browser either way; export a backup in ⚙ Settings now and then.
