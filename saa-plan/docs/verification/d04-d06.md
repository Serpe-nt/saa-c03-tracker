## Changed questions

- **q05-042** (explanation of the "lower the maximum to 3" option): it said the maximum cannot be set below the minimum *or desired* capacity. Only the first half is true. A maximum below the current desired capacity is accepted and pulls desired down with it; a maximum below the minimum is not allowed. Reworded to say the change is rejected because the minimum is still 4. Sources: https://docs.aws.amazon.com/autoscaling/ec2/APIReference/API_UpdateAutoScalingGroup.html, https://docs.aws.amazon.com/autoscaling/ec2/userguide/asg-capacity-limits.html
- **q05-047** (explanation of the keyed NAT option): "A NAT gateway lives in one AZ" is now true only for zonal NAT gateways. Reworded to "standard (zonal) NAT gateway" and added that a regional NAT gateway spans AZs automatically. Key unchanged. Sources: https://docs.aws.amazon.com/vpc/latest/userguide/nat-gateways-regional.html, https://docs.aws.amazon.com/vpc/latest/userguide/nat-gateway-basics.html
- **q05-050** (explanation of the simple-routing option): "Simple routing does not support health checks" was the wrong reason on its own. The docs say a simple alias record can point to only one AWS resource and that simple routing values are not health checked. Reworded to say both. Source: https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/routing-policy-simple.html
- **q06-007** (explanation of the Insights option): it said CloudTrail Insights covers management API calls only. Insights now analyzes management and data events. Reworded to say Insights flags unusual call and error rates and does not record each object-level request with its caller. Key unchanged. Source: https://docs.aws.amazon.com/awscloudtrail/latest/userguide/logging-insights-events-with-cloudtrail.html
- **q06-019** (explanation of the keyed Trusted Advisor option): "need a Business-level or higher support plan" uses plan names that are being retired. The docs now list Business Support+, Enterprise Support and Unified Operations for the full set of checks, and Basic for service limits plus some security and fault tolerance checks. Reworded accordingly. Source: https://docs.aws.amazon.com/awssupport/latest/user/trusted-advisor.html

## Recent-change facts the pools rely on, all confirmed

- KMS automatic rotation: symmetric encryption keys with KMS-generated material only, default 365 days; asymmetric keys are manual only (q04-029). https://docs.aws.amazon.com/kms/latest/developerguide/rotate-keys.html
- Security Hub CSPM is the former Security Hub; the new Security Hub adds correlation and risk analytics (q04-049). https://aws.amazon.com/security-hub/faqs/, https://aws.amazon.com/security-hub/cspm/
- NLB listener rules exist but match only the source IP address type (IPv4 or IPv6), on dual-stack NLBs (q05-002, q05-030). NLB QUIC listeners since 2025-11-13 (q05-046). https://docs.aws.amazon.com/elasticloadbalancing/latest/network/load-balancer-listeners.html
- Launch configurations: no new instance types since 2023-01-01; accounts created on or after 2024-10-01 cannot create them (q05-013). https://docs.aws.amazon.com/autoscaling/ec2/userguide/launch-configurations.html
- NLB cross-zone load balancing is off by default and incurs inter-AZ data transfer charges when on (q05-010). https://aws.amazon.com/elasticloadbalancing/faqs/
- DynamoDB TTL deletes "typically within a few days" without consuming write throughput (q05-026). https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/TTL.html
- CloudWatch Logs Infrequent Access differs from Standard in ingestion cost only, and the class cannot be changed after creation (q06-003). https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/CloudWatch_Logs_Log_Classes.html
- Simplified automatic recovery is on by default and reports through AWS Health events (q06-005). https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-instance-recover.html
- Control Tower: preventive controls use SCPs, RCPs and declarative policies; detective controls use Config rules (q06-021). https://docs.aws.amazon.com/controltower/latest/controlreference/control-behavior.html
- CUR 2.0 through Data Exports (q06-035). https://docs.aws.amazon.com/cur/latest/userguide/what-is-data-exports.html
- Amazon Quick Sight is the current name, part of Amazon Quick (q06-046). https://aws.amazon.com/quick/quicksight/
