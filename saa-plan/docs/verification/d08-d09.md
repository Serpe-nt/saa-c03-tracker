## Open doubt from docs/questions.md that is now settled

- **S3 encryption change (q08-003):** S3 does have an in-place encryption change. `UpdateObjectEncryption` changes an existing object from SSE-S3 to SSE-KMS, applies S3 Bucket Keys or changes the customer managed key, without copying data. Unencrypted, SSE-C and DSSE-KMS objects are not supported as sources, and SSE-S3 cannot be the target. Batch Operations exposes it as "Update object encryption".
