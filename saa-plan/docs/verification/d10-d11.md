## Changed questions

Wrong or unsupported fact:

- **q10-039** – the keyed option implied dynamic partitioning could be switched on for the existing Firehose stream; it can be enabled only when a stream is created. Option now says "create a new Firehose stream"; explanation says why. https://docs.aws.amazon.com/firehose/latest/dev/dynamic-partitioning-enable.html
- **q10-010** – explanation said FSx for Lustre "is supported only with the EC2 launch type"; Amazon ECS has no FSx for Lustre volume type at all (EBS, EFS, FSx for Windows File Server, FSx for NetApp ONTAP, S3 Files, Docker volumes, bind mounts). https://docs.aws.amazon.com/AmazonECS/latest/developerguide/using_data_volumes.html
- **q10-021**, **q11-020** – "Lambda functions time out after 15 minutes" is no longer the whole rule: on Lambda Managed Instances, asynchronous and event-source-mapping invocations can run up to 90 minutes. Explanations now state both limits; the jobs (up to 3 hours) still do not fit. https://docs.aws.amazon.com/lambda/latest/dg/configuration-timeout.html
- **q11-037** – distractor explanation claimed single-AZ interface endpoints "add cross-AZ data transfer"; inter-AZ data transfer to interface endpoints has been free since 2022-04-01. Explanation now rests on the halved hourly charge and the single-AZ dependency. https://aws.amazon.com/about-aws/whats-new/2022/04/aws-data-transfer-price-reduction-privatelink-transit-gateway-client-vpn-services/
- **q11-017** – stem and explanation called Compute Optimizer "machine-learning-based"; neither the user guide nor the FAQ page says so now (it "analyzes your AWS resources' configuration and utilization metrics"). Wording changed to match. https://docs.aws.amazon.com/compute-optimizer/latest/ug/what-is-compute-optimizer.html
- **q11-025** – stem and explanation said Savings Plans recommendations report "coverage"; the documented outputs are the hourly commitment, estimated spend and savings, and estimated utilization. "Coverage" removed. https://docs.aws.amazon.com/aws-cost-management/latest/APIReference/API_SavingsPlansPurchaseRecommendationDetail.html
- **q11-049** – the distractor said a lifecycle policy "moves all files" to Infrequent Access after 1 day; lifecycle management moves only files not accessed for that period. Option and explanation reworded. https://docs.aws.amazon.com/efs/latest/ug/lifecycle-management-efs.html

Defensibility:

- **q11-003** – "available within 12 hours" sat on the edge of Bulk's "typically 5–12 hours", so Standard retrieval was arguable. Window widened to 24 hours; explanations updated. https://docs.aws.amazon.com/AmazonS3/latest/userguide/restoring-objects-retrieval-options.html
- **q11-012** – "the link can move 80 TB in a day or two" assumed the whole 10 Gbps; softened to "within days". https://docs.aws.amazon.com/datasync/latest/userguide/what-is-datasync.html

Current names:

- **q10-023**, **q11-026**, **q11-027**, **q11-036** – "Aurora Serverless v2" is now "Aurora serverless" in the Aurora User Guide and on the product page (the string "Serverless v2" no longer appears). Options use the new name; each explanation says "(formerly Aurora Serverless v2)" once. https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/aurora-serverless-v2.html
- **q10-022** – distractor "Enable Performance Insights" replaced with "Turn on the Advanced mode of CloudWatch Database Insights"; the Performance Insights pages in the RDS and Aurora guides are now titled "Monitoring DB load with Amazon CloudWatch Database Insights". https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/USER_PerfInsights.html
- **q10-007**, **q11-010**, **q11-049** – "EFS One Zone storage class(es)" changed to "EFS One Zone file system" (file system types are Regional and One Zone; storage classes are Standard, Infrequent Access, Archive). https://docs.aws.amazon.com/efs/latest/ug/features.html

## Facts found that other pools may share

Also left in the shared notes folder for the sibling sessions.

- Inter-AZ data transfer is free for PrivateLink interface endpoints, Transit Gateway and Client VPN (since 2022-04-01); NAT gateways are not covered.
- Lambda SnapStart: no extra charge on Java runtimes; not usable with provisioned concurrency, EFS, S3 Files, or `$LATEST`. https://docs.aws.amazon.com/lambda/latest/dg/snapstart.html
- Database Savings Plans: 1-year term, no upfront, up to 35%; RDS Reserved Instances up to 69%. https://aws.amazon.com/savingsplans/database-pricing/
- Amazon ECS volume table now includes Amazon S3 Files on Fargate.
- DynamoDB reserved capacity: 1-year, or 3-year in select Regions; not for the Standard-IA table class or on-demand mode. https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/reserved-capacity.html
- QuickSight is "Amazon Quick Sight, a feature within Amazon Quick". https://docs.aws.amazon.com/quicksight/latest/user/welcome.html
